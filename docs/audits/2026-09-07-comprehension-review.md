# Collector comprehension: agent heuristic review

Date: 7 September 2026. Scope: current ORBIT 4444 Base Sepolia collector copy and decision points, for issue #56.

## Method and acceptance boundary

The user declined human testing and requested that agents finish the review. This document records five distinct **task scenarios reviewed by an agent**, not five people, sessions, interviews, or observed novice journeys. Source and page-render tests establish what explanations exist; they do not establish whether unfamiliar people understand them. This supplies agent review; it does not fulfill the original five-participant requirement unless release acceptance is explicitly revised. No participant study, physical-device study, or screen-reader listening session occurred in this review.

The original issue requested five unfamiliar-user sessions and explicitly prohibited inventing completed sessions. None are claimed here. Existing browser accessibility/performance evidence and the separate real Chrome/Reown transaction verification remain separate evidence, not comprehension scores.

## Changes and checks

Changes are limited to two onboarding strings in `packages/config/src/identity.ts` and the zero-rewards explanation in `apps/web/src/app/(collector)/learn/page.tsx`. Existing Start and Learn page tests cover the corrected stage and zero semantics. No new framework, economics, wallet behavior, or service logic is introduced.

Reviewed supporting surfaces: Start, Trade's discovery shortfall, Fleet DiscoveryProgress, contextual CollectorHelp and Learn topics, Launch review copy, shared TransactionStatus/CollectorActivity, and Rewards labels. No five-person success rate or public usability guarantee is reported. Remaining uncertainty is whether unfamiliar users can explain these concepts unaided; replacement of that participant requirement remains subject to explicit release acceptance.
