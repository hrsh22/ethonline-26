# Isolate product identity from protocol mechanics

The contracts and economic modules will use neutral domain concepts, while a small identity interface supplies user-facing names, copy, visual assets, metadata locations, and deployment-time token name and symbol. ORBIT 4444 will be the first identity adapter and a neutral test identity will be the second, making rebranding a real seam rather than scattered configuration; the selected production identity and metadata become immutable at the launch freeze, after which a rebrand would require a new deployment or migration.
