# Separate discovery randomness from finalization

Base Sepolia exposed two coupled liveness failures in the original discovery design: one 15-unit acquisition was split into independent eight-word and seven-word Chainlink VRF requests, and only the seven-word request arrived promptly; a successful callback also had to complete every identity draw and ERC-721 mint even though Chainlink does not retry a reverted callback. Each acquisition will instead create one Discovery Batch of up to FuelCore's existing 64-mutation limit, request one VRF word, and derive domain-separated entropy for every opaque protocol request from that verified seed.

The Chainlink callback stores only the seed and marks the batch ready. Its configured gas allowance drops from 2,000,000 to 200,000 because it no longer draws identities or mints NFTs. Permissionless finalization applies at most eight FuelCore mutations per transaction and can be retried without losing the seed. Batches finalize in acquisition order because choosing the order after seeds are visible could change draws from the shared without-replacement identity pool. A fully cancelled head batch can be skipped without receiving or replacing randomness.

The adapter records request, fulfillment, progress, and delayed state. A 15-minute threshold is an incident signal, not an alternate randomness source. Active delayed batches are never cancelled or re-requested: doing either would let a party discard an unfavorable result. Their holder can keep waiting or move away the backing Liquid Token, which cancels the unseen Pending Discovery and permits the queue to advance. This deliberately favors verifiable fairness over guaranteeing a collectible assignment when the external oracle is unavailable.

This decision supersedes the callback-atomic-minting and eight-word chunking statements in [ADR 0007](./0007-reproduce-discovery-in-the-poc-but-harden-production.md). Its no-preview, asynchronous VRF, and unseen-cancellation decisions remain in force.
