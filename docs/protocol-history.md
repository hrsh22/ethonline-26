## Reporting

Every material change, pause, migration, incident, and recovery must add a dated
entry here and link the relevant deployment manifest, pull request, and GitHub
issue. No private vulnerability-reporting channel is currently published. Do
not disclose secrets or exploitable details in a public issue; the maintainer
must publish and link a private contact before this proof can claim one.
